# rog-helper v0.2.1

This release keeps the repository, package metadata, and GitHub release
automation aligned on `v0.2.1`.

## Published Release Assets

- GitHub still provides the standard source tarball and source zip for the `v0.2.1` tag
- `rog-helper_0.2.1_amd64.deb` for Debian, Ubuntu, and Linux Mint-style installs
- `rog-helper-0.2.1-1.x86_64.rpm` for Fedora Workstation-style installs
- `rog-helper-v0.2.1-x86_64.AppImage` for portable download-and-run usage
- `rog-helper-0.2.1-linux-x86_64.tar.xz` for prefix-friendly `/usr/local` installs
- direct `rog-helper`, `rog-helperd`, and `rog-helper-ui` binaries for advanced local installs
- `rog-helper-0.2.1-SHA256SUMS.txt` and `rog-helper-0.2.1-RPM-SHA256SUMS.txt`

## Release Notes

- the release workflow expects the tag `v0.2.1` because `workspace.package.version` is `0.2.1`
- package layout and install paths remain the same as the previous packaging-enabled release line

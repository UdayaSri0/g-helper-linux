## Native installation

**BLOCKED:** There is no disposable Ubuntu desktop VM with systemd, D-Bus, a graphical session, and PolicyKit. No package was installed on the developer host. Native install, permissions, daemon startup/activation, diagnostics, GTK launch, PolicyKit authorization/denial, upgrade, removal, and cleanup remain untested.

Reproducible validation plan for a disposable Ubuntu 26.10 amd64 desktop VM:

1. Transfer the staged DEB and checksum manifest; verify `sha256sum --check` before use.
2. Inspect `dpkg-deb -f <deb> Package Version Architecture Depends` and `dpkg-deb -c <deb>`; verify executable modes and PolicyKit/D-Bus/systemd payload paths.
3. Run `sudo apt install ./<deb>` in the VM and record installed files with `dpkg -L rog-helper`; confirm all four executables are executable.
4. As a normal user, check the user service and D-Bus activation, then run `rog-helper setup-check` and `rog-helper privileged-status`.
5. Launch the desktop entry from the target graphical session; verify displayed name/icon and that the app runs as the normal user.
6. Inspect installed PolicyKit action and system-D-Bus policy registration. Exercise authorization denied/cancelled and missing-backend cases only; do not invoke hardware writes.
7. Close the app, inspect service shutdown, then `sudo apt purge rog-helper`; verify package files, services, activation entries and policy files were removed. Record actual output and screenshots/logs with user data redacted.

Do not use a headless container to claim GUI or PolicyKit-agent behavior. For upgrade coverage, install an older package only if a verified compatible package is available in this disposable VM.

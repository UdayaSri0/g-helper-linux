## Ubuntu 26.10 DEB

**IMPLEMENTED:** `packaging/scripts/package-common.sh` emits `polkitd`; package payload validation requires it and rejects `policykit-1`. The lifecycle test inspects the generated DEB's final `Depends` field and has a fixture for both accepted and rejected dependency lists.

**VERIFIED:** On Ubuntu 26.10 (Stonking Stingray), amd64:

- APT metadata: `polkitd` candidate `127-3ubuntu1`; `policykit-1` had no candidate. `pkexec` was available but is not called by this application.
- Generated DEB: `rog-helper_0.4.1_amd64.deb`, architecture `amd64`, with `polkitd` and no `policykit-1` in `Depends`.
- Generated shared-library requirements include `libc6 (>= 2.39)` plus host-derived GTK/GLib dependencies. Older runtimes below those floors cannot resolve this binary.
- `apt-get --simulate install ./dist/candidate/rog-helper_0.4.1_amd64.deb` resolved. This is simulation only; `polkitd` was already installed on the host.
- `packaging/scripts/check-deb-package.sh` passed.
- `packaging/scripts/test-deb-lifecycle.py` passed its temporary-root fresh install, reinstall, synthetic v1 upgrade, remove, and purge model.

**BLOCKED / UNTESTED:** No actual APT/dpkg install was performed. Service status, `setup-check`, `privileged-status`, CLI/UI launch, PolicyKit prompts, upgrade/removal on a native install, and behavior on Ubuntu 24.04/26.04, Linux Mint, or Debian remain unverified.

The candidate build was produced on Ubuntu 26.10, so its shared-library minimums reflect that build environment. Validate with the oldest claimed Ubuntu/Mint/Debian base or narrow the supported matrix; generic Debian compatibility is not established by this build.

# rog-helper v0.2.0

This release turns rog-helper into a real Linux release instead of a source-only tag.

## Highlights

- added reproducible release packaging for Debian packages, Fedora RPMs, AppImages, prefix-friendly Linux tarballs, direct binaries, and SHA256 checksum files
- aligned workspace, crate, desktop, icon, About-page, and release metadata around the same `v0.2.0` version
- added native desktop integration assets: AppStream metadata, session DBus activation, generated hicolor icons, and packaged user-service paths
- updated GitHub Actions so tagged releases build and publish installable Linux artifacts

## Debian Package Support

- added an installable `rog-helper_0.2.0_amd64.deb` for Ubuntu 24.04+, Debian, and Linux Mint-style systems
- package installs binaries, desktop integration assets, icons, AppStream metadata, session D-Bus activation, and the systemd `--user` unit in standard Debian-family paths
- added a future-ready unsigned APT repository staging helper for static hosting workflows without claiming a live repository yet

## Fedora RPM Support

- added an installable `rog-helper-0.2.0-1.x86_64.rpm` for Fedora Workstation-style systems
- package installs the UI, daemon, CLI, desktop integration assets, AppStream metadata, session D-Bus activation, and the `systemd --user` unit in Fedora-friendly locations
- tagged release automation now builds and uploads the RPM plus a Fedora-specific checksum file

## AppImage Support

- added a portable `rog-helper-v0.2.0-x86_64.AppImage` built with pinned `linuxdeploy` tooling and GTK4 runtime bundling
- the AppImage bundles `rog-helper-ui`, `rog-helperd`, `rog-helper`, the desktop entry, icon theme assets, AppStream metadata, and session D-Bus activation files
- running the AppImage does not auto-install desktop integration or enable a persistent `systemd --user` service; users who want installed session integration should prefer the `.deb`

## Included Components

- `rog-helper-ui` GTK4/libadwaita desktop app
- `rog-helperd` session daemon
- `rog-helper` diagnostics CLI
- desktop launcher, icon theme assets, AppStream metadata, session DBus activation, and systemd user service

## Notes

- hardware support is still evidence-based and remains limited to tested machines documented in the repository
- AppImage portability is validated through the Ubuntu-class release build and smoke-test pipeline, but broader distro/runtime coverage is still a follow-up area

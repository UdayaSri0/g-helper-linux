# rog-helper v0.2.0

This release turns rog-helper into a real Linux release instead of a source-only tag.

## Highlights

- added reproducible release packaging for Debian packages, prefix-friendly Linux tarballs, direct binaries, and SHA256 checksum files
- aligned workspace, crate, desktop, icon, About-page, and release metadata around the same `v0.2.0` version
- added native desktop integration assets: AppStream metadata, session DBus activation, generated hicolor icons, and packaged user-service paths
- updated GitHub Actions so tagged releases build and publish installable Linux artifacts

## Debian Package Support

- added an installable `rog-helper_0.2.0_amd64.deb` for Ubuntu 24.04+, Debian, and Linux Mint-style systems
- package installs binaries, desktop integration assets, icons, AppStream metadata, session D-Bus activation, and the systemd `--user` unit in standard Debian-family paths
- added a future-ready unsigned APT repository staging helper for static hosting workflows without claiming a live repository yet

## Included Components

- `rog-helper-ui` GTK4/libadwaita desktop app
- `rog-helperd` session daemon
- `rog-helper` diagnostics CLI
- desktop launcher, icon theme assets, AppStream metadata, session DBus activation, and systemd user service

## Notes

- hardware support is still evidence-based and remains limited to tested machines documented in the repository
- AppDir and AppImage work is still a packaging foundation, not yet the primary fully self-contained public artifact

## Privilege boundaries

- The app does not invoke `pkexec`; it requests authorization through the system PolicyKit authority over D-Bus.
- #119 changes only the DEB runtime dependency from `policykit-1` to `polkitd`, updates final-metadata validation, and adds regression coverage.
- The privileged helper remains typed and restricted; no arbitrary filesystem paths, raw HID commands, broad permissions, or root UI/daemon execution were introduced.
- Package payload checks passed for the staged DEB. No native installation or service authorization interaction was executed.

The v0.4.0 exact-file flow was downloaded into an empty directory and verified. SHA256 comparison against a manifest fetched from the same GitHub release origin detects corruption/mismatch but does not independently authenticate the publisher. No signed v0.4.1 artifacts exist.

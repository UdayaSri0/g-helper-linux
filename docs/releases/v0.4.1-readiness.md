## Validation summary

**VERIFIED on Ubuntu 26.10 amd64, candidate source tree:** formatting, locked build, locked workspace tests, Clippy with warnings denied, package/release metadata tests, package integration, Debian maintainer-script mocks, local DEB payload/lifecycle checks, `cargo audit` policy wrapper, and local SHA256 verification of six staged assets. Exact rows and commands are in [the test matrix](v0.4.1-test-matrix.md).

**PARTIALLY VERIFIED:** Ubuntu 26.10 APT dependency resolution was simulated against the locally built DEB. `polkitd` was already installed on the host; no host package was installed or removed.

The locally generated DEB also requires `libc6 >= 2.39`. The oldest supported Debian-family runtime has not been established; validate the complete shared-library dependency set on the oldest claimed target before describing broad Debian compatibility.

**BLOCKED:** isolated session smoke could not start because `dbus-run-session` is not installed. No host package was installed to satisfy this.

**UNTESTED:** native fresh install/upgrade/remove and service, CLI, GUI, D-Bus, and PolicyKit runtime behavior; Ubuntu 24.04/26.04, Mint, and Debian target installs; RPM/AppImage builds and runtime; candidate GitHub CI; candidate-specific remote asset download checks.

## Security and hardware

- `cargo audit` found no vulnerability in the candidate lockfile. It reported three unmaintained-crate warnings: `zbus_names 4.3.1` (RUSTSEC-2026-0371), `zvariant 5.9.2` (RUSTSEC-2026-0370), and `zvariant_derive 5.9.2` (RUSTSEC-2026-0372). The repository audit policy check passed; the warnings remain recorded.
- Privileged helper permissions, PolicyKit actions, system-D-Bus policy, and udev access were not loosened by #119.
- Automatic executable replacement remains disabled. Same-origin SHA256 manifests detect mismatches but do not authenticate the publisher.
- Fan Apply/Auto/recovery and Aura physical effects require supervised physical validation. Unsupported/unverified write paths remain gated. Automatic battery policy writes remain disabled.

See [security review](v0.4.1-security-review.md) and [hardware review](v0.4.1-hardware-safety.md).

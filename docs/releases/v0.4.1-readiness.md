### Administrator environment setup

Before pushing the release tag, open **GitHub → repository Settings → Environments → `release-publish`**. Add an eligible independent user or team under **Required reviewers**, enable **Prevent self-review**, and leave administrator bypass disabled. Under deployment branch/tag rules, select **Selected branches and tags**, add only the `v0.4.1` tag, then save and reload the page to confirm both protection sections persisted. The release workflow's read-only preflight also checks the saved API configuration and blocks if the environment, required reviewer, self-review setting, bypass setting, or exact tag rule is absent. Confirm an unauthorized test attempt fails before approving a release; do not use a real version tag for this test. GitHub environment approval is the human gate; the publisher creates a draft, which must be explicitly published as a separate action.
